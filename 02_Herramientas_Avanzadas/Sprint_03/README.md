# 📘 Sprint 03 — Herramientas Avanzadas para AI Engineering

## Bienvenido al Sprint 03

En este sprint dominarás las herramientas fundamentales para el procesamiento de datos en AI Engineering. Aprenderás a trabajar con NumPy para computación numérica eficiente y Pandas para manipulación de datos a escala, habilidades críticas para construir modelos de IA robustos.

Este sprint se divide en **bloques temáticos**, cada uno con su teoría y su workout.

---

## 🎯 Contenidos del Sprint

### 📖 Bloque 01 — NumPy

📖 [`01_Teoria/01_Numpy/`](./01_Teoria/01_Numpy/) · 🎯 [`02_Workout/01_Numpy/`](./02_Workout/01_Numpy/) · 📝 [`03_Material_de_Practica/01_Numpy/`](./03_Material_de_Practica/01_Numpy/) · 🧪 [`Practica_live_review/01_Numpy/`](./Practica_live_review/01_Numpy/)

**Tema Central**: Computación numérica eficiente con NumPy

NumPy es la biblioteca fundamental para computación científica en Python. En este bloque aprenderás a crear y manipular arrays multidimensionales, realizar operaciones matemáticas complejas y optimizar el rendimiento de tus cálculos.

**¿Qué aprenderás?**

- Arrays de NumPy: creación, indexación y slicing
- Operaciones vectorizadas vs. bucles en Python
- Álgebra lineal: matrices y operaciones matriciales
- Funciones matemáticas y estadísticas
- Broadcasting: operaciones con arrays de diferente forma
- Rendimiento y optimización con NumPy
- Aplicaciones en Machine Learning y procesamiento de datos

### 📊 Bloque 02 — Pandas: Lectura, Escritura y Manipulación de Ficheros

📖 [`01_Teoria/02_Pandas_lectura_escritura_ficheros/`](./01_Teoria/02_Pandas_lectura_escritura_ficheros/) · 🎯 [`02_Workout/02_Pandas_lectura_escritura_ficheros/`](./02_Workout/02_Pandas_lectura_escritura_ficheros/) · 📝 [`03_Material_de_Practica/02_Pandas_lectura_escritura_ficheros/`](./03_Material_de_Practica/02_Pandas_lectura_escritura_ficheros/) · 🧪 [`Practica_live_review/02_Pandas_lectura_escritura_ficheros/`](./Practica_live_review/02_Pandas_lectura_escritura_ficheros/)

**Tema Central**: Manipulación de datos con DataFrames

Pandas es la herramienta estándar para procesamiento de datos en Python y AI Engineering. En este bloque aprenderás a leer, escribir, limpiar y transformar datos en múltiples formatos, habilidades indispensables para preparar datasets para modelos de IA.

**¿Qué aprenderás?**

- DataFrames y Series: estructura y manipulación
- Lectura de ficheros: CSV, Excel, JSON, SQL
- Escritura de datos en diversos formatos
- Limpieza de datos: valores nulos, duplicados, outliers
- Selección y filtrado de datos
- Agrupación y agregación de datos
- Merging y concatenación de DataFrames
- Exploración y validación de datos para modelos de IA
