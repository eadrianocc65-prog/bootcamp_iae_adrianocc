NumPy — computación numérica vectorizada

NumPy es la base de todo el stack científico de Python. Introduce el ndarray: un array n-dimensional homogéneo (todos los elementos del mismo tipo) que permite operaciones vectorizadas, decenas de veces más rápidas que un bucle Python.

Crear arrays

import numpy as np

a = np.array([1, 2, 3, 4])           # desde lista
b = np.zeros((3, 4))                  # matriz 3×4 de ceros
c = np.ones(5)                        # 5 unos
d = np.arange(0, 10, 2)               # [0,2,4,6,8]
e = np.linspace(0, 1, 5)              # 5 valores entre 0 y 1
f = np.random.rand(3, 3)             # 3×3 aleatorio en [0,1)

a.shape, a.dtype, a.ndim             # (4,), int64, 1

Operaciones vectorizadas

❌ Loop en Python puro: 
resultado = []
for x in datos:
    resultado.append(x * 2 + 1)
✅ Vectorizado con NumPy: 
resultado = datos * 2 + 1

Estadística básica

a.mean(), a.std(), a.min(), a.max(), a.sum()
np.median(a), np.percentile(a, 90)

# Sobre un eje de una matriz 2D
m.mean(axis=0)    # media por columnas
m.mean(axis=1)    # media por filas

Filtrado con máscaras booleanas

edades = np.array([18, 25, 34, 17, 45, 12])
mayores = edades[edades >= 18]       # [18 25 34 45]
edades[edades < 18] = 0              # modifica in-place

# np.where: segmentación condicional
etiqueta = np.where(edades >= 18, "adulto", "menor")

Broadcasting

NumPy "estira" automáticamente arrays de distinta forma para que las operaciones encajen, siempre que las dimensiones sean compatibles.

m = np.arange(12).reshape(3, 4)   # 3×4
m + 10                               # suma a cada elemento
m + np.array([1, 2, 3, 4])          # suma por columna (broadcasting)

Errores típicos

  • Mezclar tipos: un array no puede tener a la vez int y str; se promueve al más general.
  • a = b y a[:] son vistas, no copias. Para copiar: a.copy().
  • Confundir axis=0 (columnas) con axis=1 (filas): se mira la forma del resultado.
  • Hacer un for cuando existe una operación vectorizada: lento y menos claro.

Pandas — DataFrames para datos tabulares ★

Pandas es la herramienta estándar para procesar datos tabulares. Trabaja con dos estructuras: Series (una columna con índice) y DataFrame (una tabla con filas, columnas y un índice). Internamente usa NumPy, así que hereda su velocidad.

Lectura y escritura

import pandas as pd

df = pd.read_csv("ventas.csv")
df = pd.read_excel("datos.xlsx", sheet_name="2024")
df = pd.read_json("api_response.json")

df.to_csv("salida.csv", index=False)
df.to_excel("salida.xlsx", sheet_name="out")

Primera inspección

df.head(), df.tail()           # primeras/últimas filas
df.shape, df.columns, df.dtypes
df.info(), df.describe()         # info de columnas + estadística
df.isna().sum()                 # NaN por columna
df["columna"].value_counts()      # conteo de valores únicos

Selección: loc vs iloc

OperaciónQué devuelve
df["col"]Una Series (una columna)
df[["a","b"]]Un DataFrame con dos columnas
df.loc[5, "nombre"]Celda por etiqueta de fila/columna
df.iloc[5, 0]Celda por posición entera (como NumPy)
df.loc[df.edad > 30]Filtrado booleano
df.loc[:, "a":"c"]Rango de columnas por etiqueta (inclusivo en loc)

Filtrado y ordenación

df[df["edad"] >= 18]                 # boolean mask
df[(df.edad > 25) & (df.ciudad == "Madrid")]  # varias condiciones con &

df.sort_values("salario", ascending=False)
df.sort_values(["depto", "salario"], ascending=[True, False])

Limpieza

df.drop_duplicates()
df.dropna()                            # filas con cualquier NaN fuera
df.fillna(0)                           # rellena NaN con 0
df.fillna({"edad": df.edad.mean()})   # media por columna
df["edad"] = df["edad"].astype(int)   # cambia tipo

groupby y agregación

df.groupby("depto")["salario"].mean()
df.groupby("depto").agg({"salario": ["mean", "max"], "edad": "mean"})

apply y funciones lambda

df["salario_anual"] = df["salario"].apply(lambda x: x * 12)
df["categoria"] = df["edad"].apply(lambda e: "senior" if e > 40 else "junior")

merge — unir tablas

pd.merge(empleados, departamentos, on="depto_id", how="left")
# how: "left", "right", "inner", "outer"
Idea clave Un DataFrame es un dict de columnas (Series) con un índice compartido. Casi todo lo que harás es: filtrar filas (boolean mask) y aplicar operaciones a columnas (vectorizadas o con apply).

Errores típicos

  • Usar and/or en vez de &/| al filtrar: ValueError. Y agrupa cada condición con paréntesis.
  • Confundir loc (etiqueta, inclusivo) con iloc (posición, exclusivo como listas).
  • Comparar con == cuando hay NaN: siempre da False. Usa isna().
  • Modificar un slice (SettingWithCopyWarning): usa df.loc[filtro, "col"] = ....
  • Olvidar index=False al escribir CSV: te mete una columna "Unnamed: 0" al leer de nuevo.
