# 📘 Sprint 02 — Programación Básica II

## Bienvenido al Sprint 02

En este sprint profundizamos en Python, trabajando con estructuras de datos más complejas y conceptos avanzados del lenguaje. Aprenderás a trabajar con colecciones, funciones y los fundamentos de la Programación Orientada a Objetos (OOP), herramientas esenciales para escribir código profesional y escalable.

Este sprint se divide en **bloques temáticos**, cada uno con su teoría y su workout.

---

## 🎯 Contenidos del Sprint

### 📖 Bloque 01 — Python II: Colecciones y Funciones

📖 [`01_Teoria/01_Python_II_Colecciones_Funciones/`](./01_Teoria/01_Python_II_Colecciones_Funciones/) · 🎯 [`02_Workout/01_Python_II_Colecciones_Funciones/`](./02_Workout/01_Python_II_Colecciones_Funciones/) · 📝 [`03_Material_de_Practica/01_Python_II_Colecciones_Funciones/`](./03_Material_de_Practica/01_Python_II_Colecciones_Funciones/) · 🧪 [`Practica_live_review/01_Python_II_Colecciones_Funciones/`](./Practica_live_review/01_Python_II_Colecciones_Funciones/)

**Tema Central**: Estructuras de datos y funciones para programación efectiva

En este bloque ampliarás tus habilidades de programación aprendiendo a trabajar con colecciones (listas, tuplas, diccionarios, conjuntos) y funciones. Estas herramientas te permitirán escribir código más modular, reutilizable y eficiente.

**¿Qué aprenderás?**

- Listas, tuplas y sus operaciones
- Diccionarios y manipulación de datos clave-valor
- Conjuntos (sets) y operaciones de conjunto
- Funciones: definición, parámetros y retorno de valores
- Scope y variables globales/locales
- Funciones lambda y comprensiones de listas
- Modularización y reutilización de código

### 🐍 Bloque 02 — Python III: Módulos y Programación Orientada a Objetos

📖 [`01_Teoria/02_Python_III_Modulos_OOP/`](./01_Teoria/02_Python_III_Modulos_OOP/) · 🎯 [`02_Workout/02_Python_III_Modulos_OOP/`](./02_Workout/02_Python_III_Modulos_OOP/) · 📝 [`03_Material_de_Practica/02_Python_III_Modulos_OOP/`](./03_Material_de_Practica/02_Python_III_Modulos_OOP/) · 🧪 [`Practica_live_review/02_Python_III_Modulos_OOP/`](./Practica_live_review/02_Python_III_Modulos_OOP/)

**Tema Central**: Introducción a OOP y reutilización de código mediante módulos

En este bloque entrarás en el mundo de la Programación Orientada a Objetos (OOP), un paradigma fundamental en Python y la industria. Aprenderás a crear clases, objetos y a organizar tu código en módulos reutilizables.

**¿Qué aprenderás?**

- Conceptos fundamentales de OOP: clases, objetos, atributos y métodos
- Constructor `__init__` e inicialización de objetos
- Métodos de instancia y métodos de clase
- Herencia y polimorfismo
- Módulos y paquetes en Python
- Importación de módulos personalizados
- Buenas prácticas en diseño orientado a objetos
